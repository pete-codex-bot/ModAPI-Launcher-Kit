You may also see "Configuration Script Failed" along with this error. The two errors are related.

## Steam users
Ensure the Launcher Kit is up-to-date. The latest version is **{{ site.github.latest_release.name }}**. You can check your current version by opening the Easy Uninstaller and looking in the bottom left corner.

The Launcher Kit may prompt you to launch Spore Galactic Adventures once from Steam before using the Launcher Kit. Afterwards, you should always use the ModAPI Launcher instead of launching from Steam.

Do not attempt to launch the base game or Creepy & Cute.

The error happens because Steam does not finish installing games until the first time they are launched. As a result, the game cannot start because it is not fully installed, and the Launcher Kit is unable to detect that the game is installed.

## All other users
Please [ask for help](/support) and include a support info file.
