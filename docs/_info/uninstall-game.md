## Some notes before uninstalling
If you are uninstalling the game in an attempt to solve a problem, please read through the other support pages or ask for help first. Most likely, your issue will not be resolved by simply reinstalling the game.

If you are attempting to remove all mods and return to "vanilla" Spore, you do not need to uninstall the game or Launcher Kit. You only need to uninstall all mods using the Easy Uninstaller.

---

## Uninstalling all mods
You must uninstall all mods **before** uninstalling the game or Launcher Kit.

Open the Easy Uninstaller, check the box next to each mod, and click "Uninstall Selected".

Do not uninstall the game or Launcher Kit unless no mods are listed in the Easy Uninstaller.

---

## Backing up your save data
It is strongly recommended to [back up your save data](game-save-data) before uninstalling the game.

While normal uninstallation does not affect your save data, it is a good idea to have a backup just in case.

Manual uninstallation will remove your save data.

---

## Standard vs manual uninstallation
For disc, GOG, and Steam users, the game can normally be uninstalled via Apps and Features, or through Steam/GOG Galaxy if used.

There are some circumstances in which the game should be uninstalled manually. If **any** of these apply, do not attempt to uninstall normally, instead proceed down to manual uninstallation.
- The game is installed from EA App
- You have multiple copies of the game installed (i.e. Steam and EA App, disc and EA App, disc and Origin, etc...)
- You have the base game and DLCs installed from different places (i.e. base game from disc with Galactic Adventures from Origin, or base game from Steam with DLCs from EA App, etc...)
- You have been instructed to do so by support staff

## Manual uninstallation
To completely uninstall Spore and all of its files/registry entries, use [Revo Uninstaller](https://download.revouninstaller.com/download/RevoUninstaller_Portable.zip)

### Setting up REVO Uninstaller:
- Right click on RevoUninstaller_Portable.zip, click "Extract all"
- In the newly extracted folder, run RevoUPort.exe. If you receive a UAC prompt, click "Yes"

### Uninstalling Spore:
*Note: These steps need to be repeated for Spore's expansions. Some platforms (i.e. GOG) will have the base game and its expansions bundled in one .exe*
- Locate Spore in the list, right click on the icon and click "Uninstall", then click "Continue"
  - Be sure to untick "Make a System Restore Point before uninstall"
- Spore's uninstaller should automatically run, once done, select "Advanced" under Scanning modes, and click "Scan"
- Click "Select All", then click "Delete" (this will only delete the bold registry items), then click "Next"
- Click "Select All", then click "Delete", then click "Finish"

### Removing Revo Uninstaller:
To remove Revo Uninstaller, simply remove the folder where RevoUPort.exe is located

## Reinstalling the game
After completing manual installation, reinstall *only one* copy of the game.
- If you own Spore Collection on GOG, reinstall this version only
- If you own both Spore and Spore Galactic Adventures (and optionally Creepy & Cute) on Steam, reinstall them in this order:
  - Spore
  - Spore Creepy & Cute
  - Spore Galactic Adventures
  - *NOTE: Only run Spore Galactic Adventures if prompted to do so by the ModAPI Launcher. Do not run the base game or Creepy & Cute.*
- If you own Spore and Spore Galactic Adventures on EA App, reinstalling the game will automatically prompt you to install the DLCs
  - *IMPORTANT: Do NOT install Spore from EA App if you own it from GOG or Steam. Instead, only install from GOG/Steam.*
- If using a disc version, reinstall the following in order:
  - Spore from DVD
  - Spore Creepy & Cute from DVD (optional)
  - Spore Galactic Adventures from DVD
  - [Patch 5.1]({{ page.patch151_url }})

To avoid future issues, do not install multiple versions or attempt to mix versions.

It isn't necessary to uninstall the Launcher Kit when reinstalling the game. If it remains installed, it will automatically detect your new installed game version. Verify that the expected game version appears in the bottom left corner of the Easy Uninstaller.
