In 2010, Maxis released a parts pack known as Bot Parts, which includes 14 unique creature parts. However, this parts pack was originally released through a limited promotion, initially making them unavailable to most players. Additionally, the parts pack has known issues, which can only be fixed via mods.

The parts pack is now available to all players, and a mod is available to fix the issues.

---

## Installing Bot Parts
Download the parts pack [here]({{ page.botparts_url }}). This is the official, unmodified Bot Parts pack from Maxis.

Additionally, download [SporeCrashFix]({{ page.crashfix_mod_url }}) to fix the crash caused by the parts.

Both files should be installed using the Easy Installer, just like any mod.

This allows you to use the parts in the Creature Editor, and view downloaded creations that use the parts.

---

## Sharing creatures with Bot Parts on Spore.com
While you can simply download and install the parts to use them locally, additional steps are required to share creatures made with the parts on Spore.com.

You must obtain an entitlement for the Bot Parts pack from EA support. As this is a free DLC, there is no cost to do this, and no proof-of-purchase is required, but it must be manually added to your account by an EA support agent. Contact them to have the free entitlement added to your account.

This will add a Bot Parts badge to your Spore.com profile, and afterwards you will be able to see your shared Bot Parts creatures on Spore.com.

Note that this entitlement will not appear as a game DLC in EA App. It will only appear on Spore.com. You must still download the parts using the link above.

## Known issues
*This section is purely to provide background information regarding known issues associated with Bot Parts.*
### Patch 6
The parts pack was originally bundled with a disc version patch, known as patch 6. There are no known changes introduced in this patch. However, because of how the patch installer is designed, it can result in a scenario in which the game cannot be updated or even reinstalled. Additionally, as this is an older game version than the current game version, it can no longer be installed at all on modern game versions.

Patch 6 is completely **unsupported** by both EA/Maxis and the modding community, and the Launcher Kit and most mods cannot be used if patch 6 has been installed. **Do NOT install patch 6 under any circumstances.**

The Bot Parts download above only includes the actual parts pack, not the patch, thus eliminating this issue.

### Socialization crash
The parts pack itself exposes a bug in the game. In all versions of Spore, there is a bug where if a creature does not have Sing, that creature may crash the game when it tries to socialize. Normally, this bug can never be encountered, because all creatures require mouths, and all mouths included with the base game have Sing. However, Bot Parts introduces mouths that do not have Sing, which can result in a game crash.

This bug has been fixed in [SporeCrashFix]({{ page.crashfix_mod_url }}), and therefore this mod is strongly recommended to use Bot Parts.
